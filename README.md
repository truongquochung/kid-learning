# 🐊 Bé Học So Sánh Số (1 - 10) | Kid Learning Math

Ứng dụng web học toán tương tác giúp các bé từ **5–6 tuổi (chuẩn bị vào lớp 1)** làm quen và thành thạo phép so sánh số phạm vi 1 đến 10 (`>`, `=`, `<`) thông qua hình ảnh trực quan, âm thanh sinh động và giọng đọc Tiếng Việt chuẩn.

---

## ✨ Tính năng nổi bật

- 🐊 **Bí kíp Chú Cá Sấu Háu Ăn**: Minh họa trực quan giúp bé ghi nhớ quy tắc so sánh dễ dàng ("Cá sấu luôn há to miệng về phía số lớn hơn").
- 🐶🐱🐰 **Hình ảnh con vật sinh động**: Hỗ trợ đếm trực quan với các con vật ngộ nghĩnh, kích thước lớn rõ nét.
- 🗣️ **Giọng đọc Tiếng Việt chuẩn**: Tự động phát âm câu hỏi, lời động viên và giải thích chi tiết cho bé.
- 📱 **Tối ưu Mobile 100%**: Giao diện vừa vặn màn hình điện thoại, nút bấm to nhạy, hỗ trợ rung nhẹ (Haptic Feedback) khi chạm.
- ⭐ **Hệ thống sao & Khen thưởng**: Hiệu ứng pháo hoa Confetti và danh hiệu vinh danh bé khi hoàn thành bài học.

---

## 🚀 Trải nghiệm trực tiếp

Bạn có thể mở trực tiếp file `index.html` trên bất kỳ trình duyệt nào hoặc kích hoạt **GitHub Pages** từ nhánh `main`.

---

## 🛠️ Công nghệ sử dụng

- **HTML5 / CSS3**: Giao diện Kid-friendly, Responsive Design, CSS Flexbox/Grid, CSS Animations.
- **JavaScript (Vanilla JS)**: 
  - Web Audio API (Hiệu ứng âm thanh không cần tải file ngoài).
  - SpeechSynthesis & Vietnamese Audio Fallback (Giọng đọc tiếng Việt).
  - HTML5 Canvas Particle System (Hiệu ứng pháo hoa).
